# Globaltrade

Global Tariff Market Impact & Volatility Analysis (2018–2026)
An empirical macroeconomic research pipeline analyzing 36,045 daily index records across 17 global stock indices and 139 international tariff actions from 2018 to 2026. This repository contains the raw data, event timelines, and analytical code used to dissect the divergent impacts of Initial Tariff Announcements versus Retaliatory Duties on global equity returns, volatility regimes, sector rotations, and foreign exchange dynamics.

Key Empirical Findings
The Volatility Doubling Phenomenon: While initial tariffs function as predictable sentiment shocks, retaliatory duties cause daily return standard deviations to more than double (from 0.714% to 1.537%) and elevate 20-day realized volatility by +26%.

Regional Asymmetry: U.S. and European markets exhibit severe downside vulnerability to foreign retaliations (e.g., U.S. mean daily return of -0.227% during pure retaliations), whereas Chinese equities demonstrate counter-intuitive resilience due to domestic stabilization and policy anticipation rallies (+0.346%).
